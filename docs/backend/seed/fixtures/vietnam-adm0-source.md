# Viet Nam land-boundary fixture

`vietnam-adm0-geoboundaries-2016.geojson` is the geoBoundaries open ADM0 geometry for Viet Nam, boundary ID `VNM-ADM0-46766057`, represented year 2016. The source metadata lists the boundary source as geoBoundaries/Wikipedia, with a 2023-12-12 build date and Creative Commons Attribution 4.0 license.

- Metadata: https://www.geoboundaries.org/api/current/gbOpen/VNM/ADM0/
- Geometry: https://github.com/wmgeolab/geoBoundaries/raw/9469f09/releaseData/gbOpen/VNM/ADM0/geoBoundaries-VNM-ADM0.geojson

The geometry is used only to check that synthetic SOS map pins fall on Viet Nam land. It does not certify an incident, an address, a safe rescue location, or a legal maritime boundary. The pins are approximate locality points, and the reports are fictional demo records.
